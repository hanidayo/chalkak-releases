# 찰칵 (Chalkak)

Windows용 애플 감성 화면 캡처 프로그램. 시스템 트레이에 상주하며 단축키 하나로 캡처합니다.

> **상태 안내**: 이 소스는 컴파일러가 없는 환경에서 작성되어 아직 한 번도 빌드·실행해 보지 않았습니다.
> 빌드 중 오류가 나면 오류 메시지를 그대로 알려 주세요. 바로 고치겠습니다.

## 빌드 방법

1. .NET 8 SDK 설치: `winget install Microsoft.DotNet.SDK.8`
2. 이 폴더에서 `build.bat` 실행
3. `dist\Chalkak.exe` (그리고 `찰칵.exe` 복사본)가 생성됩니다. 단일 파일, .NET 설치 불필요(self-contained).

`build.bat`은 먼저 공유 기능을 포함해 빌드하고, 실패하면 공유 기능을 뺀 채 다시 빌드합니다.

## 캡처 모드와 기본 단축키

| 모드 | 단축키 |
|---|---|
| 전체 화면 | Ctrl+Alt+PrtSc |
| 모니터 선택 | Ctrl+Alt+M |
| 마우스가 있는 모니터 | Ctrl+Alt+P |
| 활성 창 | Ctrl+Alt+W |
| 영역 | Ctrl+Alt+A |
| 자동 스크롤 | Ctrl+Alt+S |
| 수동 스크롤 | Ctrl+Alt+Shift+S |
| 지연 캡처 | Ctrl+Alt+D |
| 반복 캡처 | Ctrl+Alt+R |

설정 창에서 모두 바꿀 수 있습니다. 수동 스크롤 중 화면 추가는 Ctrl+Alt+Space.

## 기능

- 일반 캡처는 PNG로 자동 저장. 파일명 `프로그램명 또는 창 제목_YYYYMMDD_HHMMSS.png`, 중복 시 `_002` (덮어쓰기 없음)
- 캡처 직후 편집 창이 바로 열림(설정에서 끌 수 있음): 복사 / 공유 / 폴더 열기 / 편집 도구를 한 화면에서
- 반복 캡처: 기본 0.5초 간격 30초. 종료 후 갤러리에서 고른 프레임만 저장, 비슷한 프레임은 묶어서 표시(원본 삭제 없음)
- 편집기: 자르기, 펜, 직선, 화살표, 원, 사각형, 색/두께, 텍스트, 지우개, 선택 영역만 복사, 실행 취소/다시 실행, 도형 재편집, 확대/축소, 모자이크, 흐림. 저장은 `_edited` 별도 파일
- 창은 Windows 스타일(왼쪽 위 아이콘·제목, 오른쪽 위 최소화/최대화/닫기). 설정은 일반·캡처·소리·단축키·정보 탭
- 셔터 소리 5종(DSLR/필름/콤팩트/미러리스/부드러운 클릭) + 내 wav 파일, 음량 조절
- 자동 업데이트: GitHub 릴리스의 새 버전을 확인해 알림 → 클릭 시 받아서 재시작 (트레이 ‘업데이트 확인…’, 설정 > 정보)
- 트레이 상주, 시작 프로그램 등록, 라이트/다크 테마, 임시 데이터 정리 및 비정상 종료 후 복구 안내

## 알려진 한계

- 영역 선택은 한 모니터 안에서만 가능
- 스크롤 캡처는 실험적 (고정 헤더/푸터, 애니메이션이 있는 화면은 이음새가 어긋날 수 있음)
- 창 캡처는 화면 픽셀을 가져오므로 다른 창이 가리면 함께 찍힘
- 영역 캡처에는 커서가 포함되지 않음
- 편집 개체는 편집기를 닫으면 유지되지 않음
- 저장 형식은 PNG만 지원
- 마우스 제스처는 요구사항 문서에서 보류되어 구현하지 않음
- 공유는 Windows 공유 UI(WinRT)에 의존

## 새 버전 배포 (자동 업데이트)

1. `Chalkak.csproj`의 `<Version>`을 올립니다 (예: 1.0.1).
2. 커밋 후 태그를 푸시합니다: `git tag v1.0.1 && git push origin main v1.0.1`
3. GitHub Actions(`.github/workflows/release.yml`)가 빌드해서 릴리스에 `Chalkak.exe`를 올립니다.
4. 실행 중인 찰칵이 하루에 한 번(그리고 시작할 때) 확인해 새 버전을 알려 줍니다.
